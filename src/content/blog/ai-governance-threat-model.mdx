## Start with what outsiders can touch

A threat model for an AI pipeline starts with one question: what text does an agent read that someone else wrote? An agent can't reliably tell an instruction it should follow from one someone slipped into the thing it's reading. So every piece of outside text is a way in.

Everything else is trusted: the code on main, the skills and docs the agents run from, me, and GitHub itself. The skills and docs matter more than they look. If an agent could quietly change a doc every other agent reads, it would poison all of them at once.

## The threats

I mapped fourteen threats to the 2025 OWASP Top 10 for LLM applications and OWASP's list of agentic AI threats, and wrote down what stops each one today. Beyond prompt injection, the ones that worried me most:

- **An agent loosening its own guardrails.** A pull request that edits the skill, workflow, or risk check meant to stop it.
- **Excessive agency.** One credential holding every permission any agent needs.
- **Supply chain.** A malicious package update merged by an agent.
- **Runaway cost.** A loop where reviews file follow-up issues, agents build them, and the next review files more.

## The column that matters

For every defense, I marked whether it's **enforced** (GitHub, a workflow, or a plain script refuses the action no matter what the agent thinks) or **instructed** (a rule in a skill that the agent follows, and could be talked out of).

When I first wrote this, most defenses were instructed. That was the honest finding, and it drove the work in [the first post](/blog/ai-governance/). Try a few yourself:

Some stayed instructed, and that's fine as long as you know which ones. Where an instructed control guards something that matters, an enforced one backs it up. The point of the column is that nobody has to guess.

## What I'd tell someone starting one

- **List the inputs before the threats.** The threats follow from what outsiders can write, so the list does most of the work.
- **Keep the enforced/instructed column, even when it's embarrassing.** It's the column that told me what to build next.
- **Trace your scariest input by hand.** Walking the email path step by step found the one gap that a list of threats missed.
- **Put a script with no AI in it at every gate you can.** A label check or a daily cap can't be argued with.
